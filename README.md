# Express Automart concept homepage

A single-file concept homepage proposal for Express Automart Ltd, Nyeri.

- `index.html` is the whole page: HTML, CSS and JavaScript, with the photo embedded. Open it in any browser.
- The booking and job tracker card is a sample to show what a booking system could do. It does not send or save anything.
- Content still to be confirmed with the business: opening hours, exact address, full service and parts list, prices.
